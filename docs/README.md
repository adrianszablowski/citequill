# Dokumentacja Citequill

Ten folder jest źródłem prawdy o produkcie. Opisuje, co Citequill robi i jak ma działać.

Zasada: gdy kod i dokumentacja się różnią, kod jest błędny. Funkcja, która działa inaczej, niż opisuje dokument, to bug. Każda zmiana zachowania zaczyna się od zmiany dokumentu, w tym samym commicie co kod.

Pliki:

- `decisions.md`: dziennik decyzji właściciela, od najnowszej. Każda decyzja ma datę, treść i powód. Na końcu backlog: rzeczy odłożone na później.
- `git.md`: nazwy gałęzi i treść commitów.
- `research/`: raporty z researchu, które stały za decyzjami, w tym `2026-10-14-nextjs-16-4.md` o modelu Cache Components.
